# Tamil Nadu Assembly Election Analysis 2026

## Project Overview

This project analyzes the 2026 Tamil Nadu Assembly Election results using publicly available Election Commission of India (ECI) data. The objective is to identify key election stories and present them in a storytelling format for AtliQ Media.

## Research Questions

1. How did party vote shares change between 2021 and 2026?
2. How did victory margins change across constituencies?
3. Which regions experienced the highest turnout growth?

## Tools Used

* Python
* Pandas
* NumPy
* PowerPoint

## Key Insights

* Vote share shifts highlighted major changes in voter preference.
* Several constituencies witnessed tighter victory margins.
* Regional turnout patterns revealed significant participation differences.
